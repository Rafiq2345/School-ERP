# Client User Manuals (Printable Deliverables)

This directory contains client-facing user guides designed as standalone, printable deliverables for school clients.

> [!IMPORTANT]
> **Separation Mandate**:
> - These manuals are **never** embedded as an in-app page/module within the School ERP client application.
> - Each manual contains step-by-step end-user procedures and actual finalized screenshots captured during UI finalization.

## Directory Structure
- `01_admin_portal/` - School Super Admin & Operational User Manuals
- `02_employee_staff_portal/` - Staff & Employee Self-Service Manuals
- `03_teacher_portal/` - Teacher Classroom, Attendance & Grading Manuals
- `04_student_portal/` - Student Portal Guide
- `05_parent_portal/` - Parent Multi-child Portal Guide
