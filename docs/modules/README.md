# Module Technical Documentation Directory

This directory contains internal technical specifications and change logs for each modular subsystem of **School-ERP**.

> [!NOTE]
> **Internal Developer Use**:
> These documents are intended for engineering, maintenance, and technical audit. They are never exposed in the ERP user interface.

## Planned Module Specifications
1. `01_core_config` - School Profile, Sessions, Terms, Classes, Sections, Subjects
2. `02_security_rbac` - Multi-Portal Auth, 10-Action RBAC, MFA, Tenant Context, Audit Logs
3. `03_admissions_students` - Inquiries, Applications, Students, Guardians, Enrollment History
4. `04_academics_timetable` - Teacher Subject Assignments, Period Slots, Class Timetables
5. `05_attendance` - Student Daily/Subject Attendance, Staff Attendance, Leave Management
6. `06_billing_fee_management` - Fee Structures, Discounts, Installments, Voucher Batches, Payments, Zero-Balance Settlements, Bank Reconciliations
7. `07_publishing_engine` - Publishing State Machine, Bulk Operations, Portal Visibility Gates
8. `08_exams_results` - Exam Terms, Schedules, Marks Entry, GPA Calculation, Result Cards
9. `09_hr_payroll` - Departments, Designations, Contracts, Salary Structures, Payslips
10. `10_accounts_ledger` - Chart of Accounts, Double-Entry Journal, Fiscal Years, Budgets
11. `11_library` - Book Inventory, Accession Numbers, Issue/Return Tracking, Fines
12. `12_inventory_store` - Requisitions, Purchase Orders, Goods Receipt, POS/Store Sales
13. `13_communication_notices` - Circulars, Notices, Message Templates, Notification Logs
